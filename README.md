# 🕹️ FRIV-ZONE | Plataforma de Juegos Arcade & Retro

Plataforma interactiva estilo Friv que reúne los mejores juegos arcade, retro, de lógica, carreras 3D y acción, todo listo para jugar directamente desde el navegador web sin descargas ni dependencias complejas.

---

## 🎮 Catálogo de Juegos Incluidos

1. **🍄 Super Mario Bros NES** (`retro-mario-bros/`): Físicas clásicas de plataformas NES en 8-bit.
2. **🪡 Silksong: Pharloom Chronicles** (`silksong-game/`): Acción y plataformas estilo metroidvania con mecánicas de aguja y seda.
3. **🏎️ Cyber Velocity 3D** (`cyber-velocity-3d/`): Juego de carreras 3D con estética cyberpunk y alta velocidad.
4. **🐍 Culebrita Arcade Retro** (`culebrita-game/`): El legendario juego de la serpiente con efectos y modos arcade.
5. **🐛 Slither.io Neon Arena** (`slitherio-game/`): Arena multijugador arcade estilo slither/agar con bots y poderes.
6. **💣 Buscaminas Retro** (`buscaminas/`): Lógica y deducción clásica con modos y temporizador.
7. **♟️ Royal Master Chess** (`chess-game/`): Ajedrez con IA minimax inteligente, selector de dificultad y tablero dinámico.
8. **⚡ Neon Surge** (`neon-surge/`): Acción rápida, esquive de obstáculos y ritmo synthwave.
9. **🏰 Super Mario World Adventure** (`mario-game/`): Otra apasionante aventura de plataformas.
10. **🧱 Tetris Neon Arcade** (`tetris-game/`): El legendario Tetris arcade con rotación SRS, retención de pieza (Hold), música Korobeiniki y controles táctiles.
11. **🦍 Donkey Kong Arcade 1981** (`donkey-kong/`): El clásico arcade con nivel de elevadores 50m, Jumpman (Mario), Pauline, montacargas móviles, escaleras y bolas de fuego.

---

## ✨ Características Principales

- 🚀 **Zero Dependencies**: Desarrollado con HTML5, CSS3 y JavaScript moderno puro.
- 📱 **Diseño Totalmente Responsivo**: Adaptado para ordenadores, tablets y móviles.
- 🔍 **Buscador y Filtros por Categoría**: Encuentra cualquier juego en segundos.
- 🎲 **Modo Aleatorio y Favoritos**: Descubre nuevos títulos al instante.
- 🎵 **Efectos de Sonido Web Audio API**: Feedback sonoro arcade retro integrado.
- ⚡ **Compatible con Netlify / GitHub Pages / Vercel**: Incluye configuración `netlify.toml` lista para despliegue en un clic.

## 🚀 Cómo Ejecutar Localmente

No necesitas Node.js ni compiladores. Puedes abrirlo directamente:

1. Clona este repositorio:
   ```bash
   git clone https://github.com/TU_USUARIO/NOMBRE_DEL_REPO.git
   ```
2. Abre `index.html` en tu navegador favorito o usando una extensión como Live Server.
